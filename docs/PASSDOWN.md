## How to work here
- **Git:** rule 9 (every build on `beta`, committed and pushed at each checked step; `main` only on "ship it").
- **Rules:** `CLAUDE.md` (rules 7 and 8; the new game's check and build in the orientation line). One approved phase at a time; report bugs outside it, don't fix them. **Human checks:** one short open sheet in `docs/` per game, a yes/no line per thing only a person can judge, one verdict; proofs Claude runs go in the patch page.
- **Verify the new game:** `check_scripts.gd`, then the probes (every `bench/tools/*_probe.gd`: input, review, teams, motion, power, harvest, christmas, hat, sfx...), `arena_probe.gd` (`--layout=N`, `--rounds=200`, `--png=DIR`; `--write-routes` after an arena or move change, 5 minutes), `bot_probe.gd` (`--reach`, `--kid`); then a match: a server with `--no-tls --port 8095 --bots 7` and `play_probe.gd --start --bots=7 --watch=300 --predict` (`--lag=60 --jitter=30`, `--warps --stall=150`); a soak: `v2_chaos.py --spawn`. Pictures: `v2_shot.py` ([[Commands]]). Stop a test server by its PID. The old game: `tools/check_scripts.gd -- --no-net` and the harness (25/25 with `--restart-each`).
- **Serve:** the Python service (`systemctl --user restart towerbrawl`) serves both pages; the new server runs by hand. Laptop: [[laptop-server]].
