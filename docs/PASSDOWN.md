## How to work here
- **Git:** rule 9 (every build on `beta`, committed and pushed at each checked step; `main` only on "ship it").
- **Rules:** `CLAUDE.md` (rules 7 and 8; the new game's check and build in the orientation line). One approved phase at a time; report bugs outside it, don't fix them. **Human checks:** one short open sheet in `docs/` per game, a yes/no line per thing only a person can judge, one verdict; proofs Claude runs go in the patch page.
- **Verify the new game:** `check_scripts.gd`, then `input_probe.gd`, `power_probe.gd`, `arena_probe.gd` (the arena rules; `--rounds=200`, `--png=DIR`; `--write-routes` after an arena or move change), `bot_probe.gd` (`--level=...`, `--catch`, `--reach`, `--kid`), then a match: a server with `--no-tls --port 8095 --bots 7`, `play_probe.gd --start --bots=7 --watch=300` (`v2_synth.py --n 7 --bots 0` for 8 sockets; `--goal 1` for a quick end). `--lag=60 --jitter=30` on any probe; `--predict` (corrections); `--warps --stall=150` (the others' jumps); the catch test: [[Commands]]. On the laptop the service is `--quiet`: the tick is in `~/tower_brawl/bench_results/<date>/v2_server.jsonl`. Stop a test server by its PID; `pkill -f` with its arguments kills your own shell. The old game: `tools/check_scripts.gd -- --no-net` and the harness (25/25 with `--restart-each`).
- **Serve:** the Python service (`systemctl --user restart towerbrawl`) serves both pages; the new server runs by hand. Laptop: [[laptop-server]].
