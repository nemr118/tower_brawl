## How to work here
- **Git:** rule 9 (every build on `beta`, committed and pushed at each checked step; `main` only on "ship it").
- **Rules:** `CLAUDE.md` (rules 7 and 8; the new game's check and build in the orientation line). One approved phase at a time; report bugs outside it, don't fix them. **Human checks:** one short open sheet in `docs/` per game, a yes/no line per thing only a person can judge, one verdict; proofs Claude runs go in the patch page.
- **Verify the new game:** `check_scripts.gd`, then `input_probe.gd` (29 rules), `arena_probe.gd` (the arena rules; `--rounds=200`, `--png=DIR`), then a match: a server with `--no-tls --port 8095 --bots 7`, `play_probe.gd --start --bots=7 --watch=300` (`v2_synth.py --n 7 --bots 0` for 8 sockets; `--goal 1` for a quick end). The move proof with no bots: a second person `--idle --watch=25`, then `--bots=0 --start --move`. P2: `--lag=60 --jitter=30` on any probe (the clock line: late inputs); `--predict` (the corrections); the catch test: a server `--bots 0 --walls-s 0 --goal 99 --arena bench --spots 2,3`, a `--catcher` then a `--start --shooter`. On the laptop the service is `--quiet`: the tick is in `~/tower_brawl/bench_results/<date>/v2_server.jsonl`. Stop a test server by its PID (`$!`); `pkill -f` with its arguments also kills the shell. The old game: `tools/check_scripts.gd -- --no-net` and the harness (25/25 with `--restart-each`).
- **Serve:** the Python service (`systemctl --user restart towerbrawl`) serves both pages; the new server runs by hand on the PC (the service file is for the laptop). Laptop: [[laptop-server]]. Deck: `tbdash` (the old game only).

## Architecture now
- **The new game (`bench/`, its own Godot project; `bench/.gdignore` keeps it out of the old one).** `sim/sim.gd`: the rules with no nodes (TowerFall's numbers x4.5, whole-pixel movers on a 30 px grid, arrows that fly, fall, stick and are picked up, the catch, stomps, one life, the purple walls from `walls_start`; `apply_input` for a person, `_brain` for a bot seat (it waits 1 to 1.5 s after FIGHT, keeps away from the walls); `write_snapshot`; `write_fighter_state` for `T_OWN`; `predicting` and `fly_arrows` for the client's copies). `sim/proto.gd`: `VERSION`, the packets (an input 8 B x the last 4 ticks, each for the server tick it carries; a snapshot every 2nd tick: a match header, 14 B a fighter, 8 B a stuck arrow and 21 B one in the air, 9 B a zone, 7 B an event; the header carries the arena; `T_OWN` to each person after it), the buttons, the phases, the events. `sim/level.gd`: the arenas, 1920 x 1080 with wrap (`LAYOUTS`: 0 the bench, the tests' default; 1 THE KEEP and 2 THE BRIDGES as text maps; `PLAY`; `stands`, `one_drop`); `sim.set_arena`. `server/game_server.gd`: seats, the lobby, the phases (LOBBY, COUNTDOWN 3 s, ROUND_START 1.5 s, PLAY, ROUND_END 1.5 s, MATCH_END 7 s), points, bots fill, an input queue per seat (input N before tick N), a network thread, wss 8091 with the repo's cert pair; the ARENA pick (MIX takes turns each round); `--no-tls`, `--bots`, `--arena`, `--power-arrows`, `--goal`, `--walls-s`, `--spots`. `client/`: `game_client.gd` (the page, its options, keys, mouse aim, the look and its step-down), `net.gd` (hello, JSON, snapshots, the predicted clock `ticks_now`, the draw delay from your gaps, `lag`), `predict.gd` (your fighter), `present.gd` (the arrows on your tick), `world.gd` (the look T1 to T3, `set_arena`) + `fx.gd`, `hud.gd`, `lobby.gd`, `touch_sticks.gd`; `bench_client.gd` is the old benchmark page (`?bench`). Tools: `bench/tools/` (check, input_probe, arena_probe, play_probe, sim_probe, sim_prof), `tools/v2_build.sh`, `tools/v2_synth.py`, `tools/v2_shot.py`, `tools/towerbrawl-v2.service`.
- **The old game** (untouched, D11): `serve_game.py` (the relay and the web files, `/v2/` too; `client_stats.jsonl`), `scripts/global.gd` (its only network code), `arena.gd` + `arena_layouts.gd`, `player.gd`, the replay, touch and bot scripts; `tools/` the harness (`chaos_bots.py`, 25 scenarios), the deck, `tbbot.py`, `stats_table.py`.
