## How to work here
- **Git (rule 9, 2026-10-10):** two branches, `main` (the proven game, the laptop, the tags) and `beta` (every build). Commit and push on `beta` freely; `main` moves only on "ship it" after a playtest. Never `master`.
- **Rules:** `CLAUDE.md` (rule 7 plain words; rule 8 trim; the new game's check and build in the orientation line). One approved phase at a time; report bugs outside it, don't fix them. **Human checks:** one short open sheet in `docs/` per game, a yes/no line per thing only a person can judge, one verdict; proofs Claude runs go in the patch page.
- **Verify the new game:** `godot --headless --path bench --script res://tools/check_scripts.gd`, then `res://tools/input_probe.gd` (23 rules), then a match: a server with `--no-tls --port 8095 --bots 7`, `play_probe.gd --start --bots=7 --move --watch=300` (add `v2_synth.py --n 7 --bots 0` for 8 sockets; `--goal 1` on the server for a quick match end). The old game: `tools/check_scripts.gd -- --no-net` and the harness (25/25 with `--restart-each`).
- **Serve:** the Python service (`systemctl --user restart towerbrawl`) serves both pages; the new server runs by hand on the PC (the service file is for the laptop). Laptop: [[laptop-server]]. Deck: `tbdash` (the old game only).

## Architecture now
- **The new game (`bench/`, its own Godot project; `bench/.gdignore` keeps it out of the old one).** `sim/sim.gd`: the rules with no nodes (TowerFall's numbers x4.5, whole-pixel movers on a 30 px grid, arrows that fly, fall, stick and are picked up, the catch, stomps, one life; `apply_input` for a person, `_brain` for a bot seat; `write_snapshot`). `sim/proto.gd`: `VERSION`, the packets (an input 8 B x the last 4 ticks at 60 Hz; a snapshot every 2nd tick: a match header, 14 B a fighter, 8 B an arrow, 9 B a zone, 7 B an event), the buttons, the phases, the events. `sim/level.gd`: the 1920 x 1080 arena with wrap. `server/game_server.gd`: seats, the lobby, the phases (LOBBY, COUNTDOWN 3 s, ROUND_START 1.5 s, PLAY, ROUND_END 1.5 s, MATCH_END 7 s), points, bots fill, a network thread for the sockets, wss 8091 with the repo's cert pair, `--no-tls`, `--bots`, `--power-arrows`, `--goal`. `client/`: `game_client.gd` (the page, its options, keys, mouse aim), `net.gd` (hello, JSON, snapshots, the render clock 50 ms behind, own fighter from the newest), `world.gd` + `fx.gd` (the bench look, T2), `hud.gd`, `lobby.gd`, `touch_sticks.gd`; `bench_client.gd` is the old benchmark page (`?bench`). Tools: `bench/tools/` (check, input_probe, play_probe, sim_probe, sim_prof), `tools/v2_build.sh`, `tools/v2_synth.py`, `tools/v2_shot.py`, `tools/towerbrawl-v2.service`.
- **The old game** (untouched, D11): `serve_game.py` the relay and the web files (it serves `/v2/` too; `status.json`, `client_stats.jsonl`, logs with one `.1`); `scripts/global.gd` the client's only network code (JSON events, binary `sync_pos`); `arena.gd` + `arena_layouts.gd` the tower; `player.gd` the local sim and puppets; `history_ring.gd`, `replay_player.gd`, `touch_controls.gd`, `bot_brain.gd` + `bot_nav.gd`; `tools/` the harness (`chaos_bots.py`, 25 scenarios), the deck (`watch_server.py`), `tbbot.py`, `stats_table.py`, the probes.
