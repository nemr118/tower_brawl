## How to work here
- **Git:** rule 9 (every build on `beta`, committed and pushed at each checked step; `main` only on "ship it").
- **Rules:** `CLAUDE.md` (rules 7 and 8; the new game's check and build in the orientation line). One approved phase at a time; report bugs outside it, don't fix them. **Human checks:** one short open sheet in `docs/` per game, a yes/no line per thing only a person can judge, one verdict; proofs Claude runs go in the patch page.
- **Verify the new game:** `check_scripts.gd`, then `input_probe.gd` (31 rules), `arena_probe.gd` (the arena rules; `--rounds=200`, `--png=DIR`; `--write-routes` after an arena or move change), `bot_probe.gd` (`--level=easy,normal,hard`, `--catch`, `--reach`, `--kid`), then a match: a server with `--no-tls --port 8095 --bots 7`, `play_probe.gd --start --bots=7 --watch=300` (`v2_synth.py --n 7 --bots 0` for 8 sockets; `--goal 1` for a quick end). The move proof with no bots: a second person `--idle --watch=25`, then `--bots=0 --start --move`. P2: `--lag=60 --jitter=30` on any probe (the clock line: late inputs); `--predict` (the corrections); the catch test: a server `--bots 0 --walls-s 0 --goal 99 --arena bench --spots 2,3`, a `--catcher` then a `--start --shooter`. On the laptop the service is `--quiet`: the tick is in `~/tower_brawl/bench_results/<date>/v2_server.jsonl`. Stop a test server by its PID (`$!`); `pkill -f` with its arguments also kills the shell. The old game: `tools/check_scripts.gd -- --no-net` and the harness (25/25 with `--restart-each`).
- **Serve:** the Python service (`systemctl --user restart towerbrawl`) serves both pages; the new server runs by hand on the PC (the service file is for the laptop). Laptop: [[laptop-server]]. Deck: `tbdash` (the old game only).

## Architecture now
- **The new game (`bench/`, its own Godot project; `bench/.gdignore` keeps it out of the old one).** `sim/sim.gd`: the rules with no nodes (TowerFall's numbers x4.5, whole-pixel movers on a 30 px grid, arrows that fly, fall, stick and are picked up, the catch, stomps, one life, the purple walls from `walls_start`; `apply_input` for a person and, through `sim/brain.gd`, for a bot (levels OLD = p3.1's brain, EASY, NORMAL, HARD); `sim/routes.gd` + `routes.json`: the places, the moves, the route map; `write_snapshot`; `write_fighter_state` for `T_OWN`; `predicting` and `fly_arrows` for the client's copies). `sim/proto.gd`: `VERSION`, the packets (an input: 8 B x the last 4 ticks; a snapshot every 2nd tick, its header with the arena; `T_OWN` to each person after it), the buttons, the phases, the events. `sim/level.gd`: the arenas, 1920 x 1080 with wrap (`LAYOUTS`: 0 the bench, the tests' default; 1 THE KEEP and 2 THE BRIDGES as text maps; `PLAY`; `stands`, `one_drop`); `sim.set_arena`. `server/game_server.gd`: seats, the lobby, the phases, points, bots fill, an input queue per seat (input N before tick N), a network thread, wss 8091 with the repo's cert pair; the ARENA pick (MIX takes turns each round), the bots level; round and match lines in `v2_server.jsonl`; `--no-tls`, `--bots`, `--arena`, `--bot-level`, `--soak`, `--goal`, `--walls-s`, `--spots`. `client/`: `game_client.gd` (the page, its options, keys, mouse aim, the look), `net.gd` (snapshots, the predicted clock `ticks_now`, the draw delay, `lag`), `predict.gd` (your fighter), `present.gd` (the arrows on your tick), `world.gd` (the look T1 to T3, `set_arena`) + `fx.gd`, `hud.gd`, `lobby.gd`, `touch_sticks.gd`; `bench_client.gd` is the old benchmark page (`?bench`). Tools: `bench/tools/` (check, input_probe, arena_probe, bot_probe, play_probe, sim_probe, sim_prof), `tools/v2_build.sh`, `v2_synth.py`, `v2_shot.py`, `v2_soak_report.py`, `towerbrawl-v2.service`.
- **The old game** (untouched, D11): `serve_game.py` (the relay and the web files, `/v2/` too; `client_stats.jsonl`), `scripts/global.gd` (its only network code), `arena.gd` + `arena_layouts.gd`, `player.gd`, the replay, touch and bot scripts; `tools/` the harness (`chaos_bots.py`, 25 scenarios), the deck, `tbbot.py`, `stats_table.py`.
