# v0.0.3 - Match End, Roster & Version Banner

**Date:** 2026-09-02 · **Phase:** Cleanup before Phase 1 · **Harness:** 9/9 (new match_end scenario)
**Report:** [harness_report_v0.0.3.json](../harness_report_v0.0.3.json)

> The match now ends at five crowns on the server, the arena only spawns fighters that are actually in the match, and stale builds are told so on screen.

## Changes
- Server: a round winner reaching `MATCH_SCORE_LIMIT` (5) marks `round_end.match_over`; the banner gets 6 s, then a clean lobby via `return_to_lobby`. Never another `new_round` after a win.
- Client: `Global.playing_players` tracks the server's match roster (snapshots, `scene_transition`, `player_left`, `return_to_lobby`); the arena spawns only that roster, frees stale puppets, hides other HUD panels, and shows queued players a banner. Locked-in classes from the join snapshot are applied so late arrivals draw the right champions.
- `Global.is_connected` renamed `ws_connected`: it shadowed `Object.is_connected()` and broke the `_exit_tree` disconnect until the compile checker caught it.
- Version mismatch: `net_version_error` signal, red label in the lobby, banner in the arena, join buttons disabled with a reload hint.
- `bump_build.sh --clean` prunes older versioned builds (79 MB instead of 99 MB).
