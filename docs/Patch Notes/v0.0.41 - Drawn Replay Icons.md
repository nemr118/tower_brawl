# v0.0.41 - Drawn Replay Icons

**Date:** 2026-09-07 · **Phase:** the replay overlay's rewind / play / stop marks are drawn shapes, not font glyphs; the v0.1.0 release candidate, deployed to the laptop for the family night · **Harness:** 24/24 with `--restart-each`, no Minor
**Report:** [harness_report_v0.0.41.json](../harness_report_v0.0.41.json) · release: [[release-v0.1.0]]

> Playing against the laptop server, the user saw boxes where the VHS replay shows its `◄◄ REW`, `► PLAY`, `► SLOW` and `■ STOP` label. Those marks were characters, and the font the web build ships has no glyph for them, so a browser draws its "missing glyph" box. The deck on the laptop screen was fine (a screenshot over ssh showed every symbol in its Tape column); the game was not. Now the mark is a shape drawn with polygons, so it looks the same on every device whatever fonts it has. One file changed, `scripts/replay_player.gd`.

## Changes
- **`scripts/replay_player.gd`.** `_label()` returns the word only (`REW`, `PLAY`, `SLOW`, `STOP`). New `_draw_icon(c, at, col)` draws the mark for the current phase with its bottom-left corner on the label's baseline and returns its width: `rew` two left-pointing triangles, `stop` a square, anything else one right-pointing triangle. `ICON_H = 14`, `ICON_W = 12` px. Each shape gets a dark 3 px outline (`draw_polyline`) under the white fill (`draw_colored_polygon`), the same contrast the text has from `draw_string_outline`. `_draw_overlay` draws the icon at x 12, the word 6 px after it, and the counter moved from x 96 to 104 to make room. The replay timing, the ghosts, the flash, the caption and the `📼 [Replay]` console lines are unchanged.
- **`tools/watch_server.py --controls`: the bot menu.** `a` (or the **+ bot** button) no longer adds a bot at once; it opens a `bots` panel with one clickable chip per persona and its key: `1` wanderer, `2` chaser, `3` sniper, `4` turtle, `5` rusher, `6` griefer, each with a one-line description and the class it plays. `a` inside the menu adds the next persona in the list (what the old key did), `r`, `x` and `w` still work from inside it, Esc closes it. While the menu is open the digits go to the menu, not to the event filter. The panel also lists the bots in the game with their personas. `bot_action` takes a persona and passes it to `tools/tbbot.py add`. `tools/console.sh` and [[laptop-server]] name the menu. The PC's `tbdash` alias runs this same file, so both decks match once the laptop has the build.
- **`tools/watch_server.py --controls`: the about panel.** Key `i` (or the **info** button) opens a panel with the game in one line, the version, the public GitHub link `https://github.com/nemr118/tower_brawl`, what `docs/` holds, and what this screen is. For the person at a family night who asks about the code. Esc or `i` closes it. `tools/console.sh` prints the link in the help box too.
- **The SERVER panel is on by default.** The PC's `tbdash` alias never passed `--controls`, so the bot menu and the info key were invisible there. `tools/watch_server.py` now shows the panel unless `--no-controls` is given; `--controls` still works for the laptop's console script and old aliases. A deck that is already open keeps the old code: quit it with `q` and start it again.
- **Docs.** Master sheet: section 1.3 names the strip in words, section 6.4 asks that the marks are shapes on every device. Release candidate moves to v0.0.41 in [[release-v0.1.0]], PASSDOWN and the sheet.
