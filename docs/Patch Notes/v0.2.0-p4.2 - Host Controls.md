# v0.2.0-p4.2 - Host Controls

**Date:** 2026-10-24 · **Phase:** P4, host controls (the user asked at a family gathering, with the server on the ROG laptop: "add bots, remove bots, kick players, player stats", on an Ignition page hosted on the desktop) · **Harness:** `tools/v2_host_check.py` on the PC
**Report:** `tools/v2_host_check.py` (every host command against a test server); the host page: `~/Work/tower_brawl_ignition/build_host.py`

> The game server has a host port now. The host page in Ignition, on the desktop, uses it. From there you can add and remove bots, set their level and the arena, start and end a match, and kick a player back to watching. The page also shows each player's numbers for tonight: kills, deaths, catches, shots, round wins and match wins. The host port only answers on the server's own machine. The desktop reaches it through an SSH tunnel.

## Changes
- **1. The host port** (`bench/server/game_server.gd`, `--admin-port 8092`). It answers on 127.0.0.1 only (`--admin-bind` changes that), in plain http with JSON. `GET /state`: the phase, the round, the settings, the 8 seats (each person's address and ping), who is watching, the tick, the players' numbers, the last 80 events. `POST /bots {n}`, `/bot_level {n}`, `/arena {n}` work any time. In a match they count from the next round, because the bots are seated again when each round starts. `POST /kick {seat}`: the person goes back to watching and reads "The host took your seat. Press JOIN to play again." They can join again. `POST /start`, `/stop` (the match ends, back to the lobby). A reply is `{ok, text, state}`: 400 when refused, 404 for a path it does not know. One request per connection, answered on the game thread between ticks.
- **2. The players' numbers for tonight**, by name: matches, match wins, rounds, round wins, kills (arrows, stomps, other), deaths, self kills, catches, shots, the hit rate (arrow kills per shot) and K/D. Bots are kept apart from people. They are saved after each round in `bench_results/<date>/v2_stats.json` and read back when the server starts again that day.
- **3. A freed seat starts at 0.** A person who leaves or is kicked no longer passes their points and crowns to the bot or person who sits there next. Kicks would have made that common.
- **4. The round lines carry the seat names** (`names` in `v2_server.jsonl`).
- **5. A `[HOST]` line** in the journal for each host command.
- **6. The panel** (`tools/v2_dash.py`, the server laptop's screen) lists the seats from the host port and has keys: + and − for the bots, K and a seat number to kick.
- **7. The service file** (`tools/towerbrawl-v2.service`) starts the server with `--admin-port 8092`.
