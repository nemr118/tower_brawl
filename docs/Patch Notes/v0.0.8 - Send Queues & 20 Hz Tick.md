# v0.0.8 - Send Queues & 20 Hz Tick

**Date:** 2026-09-02 · **Phase:** Phase 3a, send side · **Harness:** 17/17
**Report:** [harness_report_v0.0.8.json](../harness_report_v0.0.8.json) · **Playtest:** [[Playtest v0.0.8]] (pass; one backlog item: Ranger reload loses stuck-arrow pickups)

> The relay no longer blocks on any client, movement runs at 20 Hz with idle suppression, and every movement sample carries a tick number for Phase 3b interpolation.

## Changes
### Server (`serve_game.py`)
- **Per-client send queues.** Every socket has a `ClientConn` with a bounded queue and its own writer thread. `broadcast()` builds one frame and enqueues it; nothing blocks the relay any more. When a queue backs up (128 frames / 32 KB) movement frames are dropped first and events are kept; a queue that fills with events alone closes the client.
- **Stall detection.** The writer samples the socket's kernel send backlog (`SIOCOUTQ`) about once a second; a backlog above 2 KB that never shrinks for 5 s means the peer stopped reading, and it is disconnected (the reader thread is woken with `shutdown()` and runs the normal leave path). A hidden browser tab keeps reading, so it is never confused with a stalled one. `[STATS]` gained `drop=`.
- `sync_pos` is now 11 bytes: a u16 tick after the sender byte.

### Client
- `player.gd`: movement samples at 20 Hz (was 30). Idle suppression: an unchanged sample (0.1 px, 0.1°, flags) is skipped, but the state is repeated every 0.5 s so late joiners and lost packets are corrected. A tick counter goes out in every sample and continues across a reload (persisted with the combat state). Received samples older than the newest one are dropped, wrap-aware, with a restart tolerance; `player_joined` resets a puppet's sequence.
- Guards: no fighter spawns with an id outside 1–4, a fighter with an invalid id never reads input, the lobby ignores input before a slot is assigned (a one-off `p0_left` error in one fleet run, not reproduced since).
- Headless test clients derive their client token from their name instead of the shared `user://` file.

### Harness
- 11-byte codec with tick, 20 Hz default, the same idle suppression as the client, an `oracle.movement-out-of-order` check, and an order-preserving latency model (jitter can no longer reorder, as TCP cannot). `slow_reader` expects the drop within ~35 s and passes.
