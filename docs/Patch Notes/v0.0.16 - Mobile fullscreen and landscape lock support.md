# v0.0.16 - Mobile fullscreen and landscape lock support

**Date:** 2026-09-03 · **Phase:** Phase 3b, before step 5 (the playtest with real people) · **Harness:** 17/17
**Report:** [harness_report_v0.0.16.json](../harness_report_v0.0.16.json)

> On a phone, one tap now makes the game fill the whole screen and turns the phone sideways. Phones that cannot do that get a sign that asks you to turn the phone by hand.

## The problem
On a phone the browser has bars at the top and bottom. They eat part of the game. The game is also made to be played sideways (wide, not tall). Before this build the player had to fix both by hand every time.

## What we did
We did not touch the game code. We only changed the web page that holds the game. The game runs inside a box on a web page, and Godot builds that page for us. Now Godot builds it from our own page, `web/shell.html`, which has three little helpers on top of the game:

- **A dark sheet that says "Tap to play full screen".** It shows up on phones right away, even while the game is still loading. One tap does two things: it asks the browser to fill the whole screen, and it asks the phone to turn sideways and stay that way. Then the sheet goes away.
- **A small button in the top right corner.** If you leave full screen (on Android, the back swipe does that), the button comes back. Tap it to fill the screen again.
- **A "Please turn your phone sideways" sign.** It shows when a touch screen is held upright. It goes away as soon as the phone is sideways. It has no code at all, just a style rule, so it works on every phone. On an iPhone it also tells you how to add the game to your home screen, because an iPhone browser cannot fill the screen by itself.

A PC never sees any of this. The page checks for a touch screen first.

## What each phone does
| Phone | Fill the screen | Turn sideways by itself | What you see |
|---|---|---|---|
| Android (Chrome, Firefox) | yes | yes | tap once, done |
| iPad (Safari) | yes | no | tap once, then turn the iPad by hand if the sign shows |
| iPhone (Safari) | no | no | the sign asks you to turn it; the tip says how to add it to the home screen |

## Changes
- **New file `web/shell.html`.** Godot's normal page plus the three helpers. The comments in it tell the same story as this page.
- **`export_presets.cfg`.** Tells Godot to build the page from `web/shell.html`.
- **`bump_build.sh`.** After the export it checks that the page really has the helpers. If the setting above ever gets lost, the build stops instead of shipping a plain page.
- **Page setting `viewport-fit=cover`.** Lets the game reach under the camera notch on new phones.

## How to test it on your phone
1. Open `https://192.168.4.21:8443/play`. Hard reload if the console says VERSION MISMATCH.
2. You should see the dark "Tap to play full screen" sheet. Tap it.
3. Android: the bars vanish and the phone turns sideways on its own. iPad: the bars vanish; turn it by hand. iPhone: the sign asks you to turn it.
4. Swipe back or pull the bars down. The small corner button should come back. Tap it.
5. Look at the browser console. Lines that start with `[shell]` tell you what the phone could not do. That is fine. There should be no red errors.
