# v0.0.6 - Playtest Fixes

**Date:** 2026-09-02 · **Phase:** Playtest fixes (before Phase 3a) · **Harness:** 16/17
**Report:** [harness_report_v0.0.6.json](../harness_report_v0.0.6.json) · **Playtest:** [[Playtest v0.0.5]]

> Everything the first human playtest exposed, with the real root causes from the server log: the PC tab (not the phone) was being dropped after 10 s in the background, deaths could only be reported by the victim, and saved slot numbers were honoured forever.

## Changes
### Server (`serve_game.py`)
- Liveness is TCP keepalive (idle 10 s, 5 s probes, 3 tries) instead of a 10 s application timeout. A browser tab in the background stops running Godot for minutes but its socket is alive; it keeps its seat. A dead peer is detected in ~25 s.
- Observer-authoritative deaths: any connected fighter may report a death; the first report per victim counts, repeats within 1.5 s are the same death. Melee and stomp kills count for the first time in multiplayer.
- Client token (`request_join.token`): a saved slot is honoured only with the token that held it (hot reclaim, rejoin grace, or left the lobby < 2 min ago). Everyone else fills 1 → 2 → 3 → 4. A stranger can no longer evict a seat.
- Rejoin grace (8 s): a fighter that disconnects mid-match keeps seat, name and class; a page reload comes back into the same fight (`player_joined` now carries `playing_players`). The round is decided only when the grace runs out, and a held seat is neither winner nor loser.
- Forfeit grace (1.5 s) after an explicit leave: two players leaving together produce an idle reset, not a forfeit win.
- `arena_flips` in every snapshot so late arrivals draw the platforms the right way up. Names sent before JOIN are kept per socket and applied on assignment.

### Client
- `global.gd`: client token in localStorage; on a disconnect the slot is remembered and re-requested automatically after reconnect (also when the saved slot is < 2 min old); the scene is corrected to the server's state (a client that reconnects after the match ended goes to the lobby instead of staying in an empty arena); `set_name` repeated on `assign_id`; every player input action released on focus loss.
- `player.gd`: `take_hit` reports the death whoever detected it (the old `TargetBot` hook is gone).
- `touch_controls.gd`: shown when the user-agent check, feature tags or `DisplayServer.is_touchscreen_available()` say touch, and revealed on the first screen touch regardless.
- `arena.gd`: platform rotation applied from `Global.arena_flips` on load.

### Harness
- Bots carry tokens; the model understands held seats; new scenarios `silent_client`, `reload_mid_match`, `simultaneous_leave`, `observer_death`; `reclaim` also checks that a stranger cannot take an occupied slot; bots respect spawn invulnerability like the real client.

## Metrics
| Playtest symptom | v0.0.5 | v0.0.6 |
|---|---|---|
| Hidden tab dropped | after 10 s | never (TCP alive) |
| Kills registered in a session | 1 (a thorn, victim-detected) | every observed hit, deduped |
| Slot on join | saved number, forever | lowest free, or own seat with token |
| Reload mid-match | instant forfeit | same seat within 8 s |
| Both leave together | forfeit win | idle reset, no winner |
