# v0.0.2 - Stability Pass

**Date:** 2026-09-02 · **Phase:** Phase 0.5 · **Harness:** 8/8 (was 1/8 on v0.0.1)
**Report:** [harness_report_v0.0.2.json](../harness_report_v0.0.2.json)

> Every defect the harness put on record against v0.0.1 fixed, on both sides of the wire.

## Changes
### Server
- Packet doubling: a socket holding a slot is removed from the spectator list (put back on `leave_slot`); `broadcast` dedupes by socket identity as a guard. Halved every inbound number.
- `TCP_NODELAY` on client sockets (40 ms delayed-ACK stalls gone).
- Round end, next round, match setup and reset are single functions judged on live state; the old per-thread `active` snapshot hung rounds whenever the first joiner was eliminated last.
- Hot reclaim evicts the old socket silently (no false `player_left`, no duplicate `player_joined`).
- `match_started` / `force_start` state guard: one `scene_transition` per match.
- Idle reset to LOBBY when the last player leaves; fewer than two players left ends the match into the lobby instead of looping rounds.
- Sender stamped from the assigned slot on every relayed packet; server-only packet types from clients are dropped; failed sends close the socket so the owning thread cleans up.

### Client
- `force_die()` in `player.gd` (idempotent, silent): deaths, banners, stocks and respawns work again on every client.
- No local 2.6 s round auto-advance; only the server's `new_round` starts a round.
- Arena connects Global signals from a table in `_ready` and disconnects in `_exit_tree`; post-await guards. The null-tree crash on `return_to_lobby` is gone.
- Dead `player_died` signal wiring removed.

### Housekeeping
- `debug.log`, `server.log` and `.godot/` untracked and ignored.
