# v0.0.1 - Instrumentation & Build Pipeline

**Date:** 2026-09-02 · **Phase:** Phase 0 · **Harness:** 1/8 on the first harness run (the baseline: doubling bug, round hang, false player_left, quadruple transition all on record)
**Report:** [harness_report_v0.0.1_unpatched.json](../harness_report_v0.0.1_unpatched.json)

> Measurement before optimisation: a build script that cannot ship a broken script, counters on both ends, and the bots turned into a test harness.

## Changes
- `bump_build.sh`: compile check with autoloads live (`tools/check_scripts.gd`, because `godot --check-only` cannot see `Global`), patch-version bump in `scripts/global.gd` mirrored into `serve_game.py`, export, `index_<version>.pck` + `mainPack` patch. The server re-reads the version from `global.gd` on each join, so a rebuild needs no restart.
- `global.gd`: NetStats counter (packets, bytes, per-type breakdown every 5 s), `--autojoin` headless test hook, VERSION MISMATCH console line.
- `serve_game.py`: movement no longer logged per relayed packet (the largest server cost), `[STATS]` line every 10 s, `pong` reply.
- `auto_deploy.gd` guarded so headless runs no longer trigger a background export.
- Chaos bots brought into the repo with the real packet schema, then rewritten as a harness: protocol oracle, per-type schema, duplicate detection, mortality, scenario runner with seeds, atomic JSON reports.
